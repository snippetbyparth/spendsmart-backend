# SpendSmart Backend 🔧

The FastAPI + PostgreSQL backend powering [SpendSmart](https://github.com/snippetbyparth/spendsmart), a personal expense tracking mobile app.

---

## 📡 Overview

This service handles user authentication and transaction storage for the SpendSmart Flutter app. It exposes a REST API consumed by the mobile client, with all data persisted in PostgreSQL.

---

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Framework | FastAPI |
| Database | PostgreSQL |
| ORM | SQLAlchemy |
| Auth | JWT (`python-jose`) + `passlib` (bcrypt) |
| Server | Uvicorn |

---

## 📡 API Endpoints

### Auth
| Method | Endpoint | Description |
|---|---|---|
| POST | `/auth/register` | Create a new user (hashes password before storing) |
| POST | `/auth/login` | Verify credentials and return a JWT access token |

### Transactions
| Method | Endpoint | Description |
|---|---|---|
| GET | `/transactions/?user_id={id}` | Get all transactions for a user |
| POST | `/transactions/?user_id={id}` | Create a new transaction |
| DELETE | `/transactions/{transaction_id}` | Delete a transaction |

Full interactive API docs are auto-generated by FastAPI at `/docs` once the server is running.

## 🚀 Getting Started

### Prerequisites
- Python 3.10+
- PostgreSQL installed and running

### Setup

```bash
git clone https://github.com/snippetbyparth/spendsmart-backend.git
cd spendsmart-backend

python3 -m venv venv
source venv/bin/activate

pip install -r requirements.txt
```

### Database setup

```bash
psql postgres
```

```sql
CREATE DATABASE spendsmart;
CREATE USER spenduser WITH PASSWORD 'password123';
GRANT ALL PRIVILEGES ON DATABASE spendsmart TO spenduser;
GRANT ALL ON SCHEMA public TO spenduser;
ALTER DATABASE spendsmart OWNER TO spenduser;
```

### Environment variables

Create a `.env` file in the project root:

```
DATABASE_URL=postgresql://spenduser:password123@localhost/spendsmart
SECRET_KEY=your-secret-key-here
ALGORITHM=HS256
```

### Run the server

```bash
uvicorn main:app --reload
```

The API will be live at `http://127.0.0.1:8000`, with interactive docs at `http://127.0.0.1:8000/docs`.
